# Week 2 - Object Detection with YOLO

## Task
Run pretrained YOLO model on video, detect people only, draw boxes with confidence, save output.

## Files
- `main.py` - Main script
- `Video.mp4` - Input video
- `output_video.mp4` - Output with detections

## How to Run
1. Install: `pip install opencv-python ultralytics`
2. Run: `python main.py`
